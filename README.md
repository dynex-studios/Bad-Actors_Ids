# 🔐 Bad-Actor Detected Players

A community-driven, open-source registry of verified Roblox Bad-Actor IDs designed to bolster game security and streamline moderation.

### 📜 Database Policy

* **Permanent Entries:** Entries are permanent unless a formal appeal is successful. Standard requests for removal without an official appeal will be ignored.
* **Appeals Process:** To submit a formal appeal, please visit our [Discord Server](https://discord.gg/vZZUvvCp2c).
* **Proprietary Logic:** To maintain the effectiveness of our security measures, the source code for our system remains private.
* **Purpose:** This public database is maintained to accelerate detection speeds for our systems and to provide developers with a shared resource for identifying known external bad actors.
